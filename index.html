Guia de Bolso de Git

Comandos Essenciais

git init

Inicia um novo repositório Git na pasta atual

git add

Adiciona arquivos modificados para o commit

git commit -m "mensagem de commit"

Cria um commit com arquivos adicionados e uma mensagem

git status

Mostra o estado dos arquivos no diretório de trabalho

git log

Mostra historico de commit

git fetch

verifica se tem alteraçao do repositorio para o local

git push -u origin main

manda as alterações ao repositório

git pull

puxa as mudança do repositorio ao local

git clone

clona um repositório existente

git remote add origin

conecta o repositório local ao repositório remoto

Dica: use "git status" antes de commitar para saber o estado do arquivo
